# 🚦 Chandigarh City Traffic Analysis | Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing city traffic patterns in Chandigarh using Microsoft Excel. It explores traffic volume, traffic density, average vehicle speed, weather conditions, road types, and accident reports.

The project uses data analysis techniques, Pivot Tables, Excel formulas, and dashboard visualizations to transform raw traffic data into meaningful insights.

## 🎯 Project Objectives

- 🚗 Analyze vehicle traffic volume across different locations.
- 📍 Compare traffic patterns across Chandigarh sectors and areas.
- 🚦 Understand the distribution of High, Medium, and Low traffic density.
- 🛣️ Analyze average vehicle speed and road types.
- 🌦️ Explore the relationship between weather conditions and traffic patterns.
- ⚠️ Examine accident reports across different locations.
- 📊 Present key information through an Excel dashboard.

## 📂 Dataset Information

The workbook contains 5,000 traffic records and 13 columns.

| Column | Description |
|---|---|
| Location | Traffic location in Chandigarh |
| Date | Date of traffic record |
| Time | Recorded time |
| Vehicle_Count | Number of vehicles |
| Traffic_Density | High, Medium, or Low |
| Average_Speed | Average vehicle speed |
| Road_Type | Type of road |
| Weather | Weather conditions |
| Accident_Reported | Accident report status |
| Signal_Status | Traffic signal status |
| Hour | Extracted hour |
| Day Name | Day of the week |
| Month | Month of the year |

## 📊 Key Analysis Performed

### 1. Traffic Volume Analysis 🚗
Analyzed total vehicle counts across different locations to understand traffic distribution.

### 2. Traffic Density Analysis 🚦
Examined the distribution of High, Medium, and Low traffic density records.

### 3. Location-Wise Analysis 📍
Compared vehicle counts and average traffic volume across different Chandigarh locations.

### 4. Speed Analysis 🛣️
Analyzed average vehicle speed to understand traffic movement.

### 5. Weather-Based Analysis 🌦️
Explored traffic patterns under different weather conditions, including Sunny, Cloudy, Rainy, and Foggy.

### 6. Accident Analysis ⚠️
Examined accident report records and their distribution across locations.

### 7. Hourly Traffic Analysis 🕒
Analyzed vehicle counts across different hours of the day to explore hourly traffic patterns.
